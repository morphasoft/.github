# Morpha

**Morpha** is a parametric 3D CAD for Windows that AI apps can operate through the [Model Context Protocol (MCP)](https://modelcontextprotocol.io).
Ask in plain words, and the AI builds the model, edits it and checks it, using the same operations as the Morpha screen. Everything the AI does appears in the feature history, so a person can undo it, edit it or fix it.

## What you can do with it

| Area | Examples |
| --- | --- |
| Parts | sketches with dimensions and constraints, extrude, revolve, sweep, loft, holes and threads, fillets, chamfers, shell, patterns |
| Assemblies | mates, arrangements, exploded views, interference check |
| Drawings | JIS-style sheets, projected and section views, dimensions, PDF and DXF |
| Files | STEP, IGES, STL and DXF import and export |
| AI | about 270 operations through MCP, from an AI app of your choice |

Morpha is a commercial desktop application and is not open source. The repositories here hold documentation and files for connecting AI apps.
